# Demo script (about 90 seconds)

Before judges arrive: `./scripts/check_env.sh` all green, dashboard on **Live Loop** in **Demo mode**, FirmGen monitor open on a second screen, mode **ARMED**.

| Time | Show | Say |
|---|---|---|
| 0:00 | Rig: camera, cardboard road, roadside sign (ESP32 + LEDs + buzzer), dashboard | "Thousands of tapirs, anteaters and maned wolves die on Brazilian roads every year, and drivers get no warning. WildGuard sees the animal and warns the driver, in real time." |
| 0:10 | Loop strip: PipeGen FPS, Bridge, Broker, ESP32 online, green LED | "The camera runs a CraftifAI PipeGen pipeline: our YOLOv8 model compiled to TensorRT on DeepStream. The roadside unit runs firmware generated by FirmGen from our PRD." |
| 0:20 | Wave a hand near the HC-SR04: amber LED, state ARMED | "The unit has its own sensors. When something is close, it arms." |
| 0:30 | Tapir card in front of the camera | PipeGen box appears, then the event in the feed, red strobe and beeps, toast "CRITICAL · Tapir · ACK in X ms" |
| 0:45 | Point at the toast and the timeline | "That is measured, not claimed: capture to actuator to acknowledgement in X ms. The board switched the LEDs on Y ms after receiving the message." |
| 0:55 | Jaguarundi card | Milder amber blink, no buzzer. "Response depends on species and on whether the board's own sensor agrees. The board decides that, not the laptop." |
| 1:05 | Person or toy in frame | No alert. "K-frame confirmation, per-class thresholds and the road zone keep false alarms down." |
| 1:15 | Evidence tab: Pipeline IR graph, TensorRT report, FirmGen traceability report, UART `[WG]` lines, HIL results | "Every PRD requirement is traced to code and tests, and 19 acceptance checks ran on this board." |
| 1:25 | Optional: stop the broker | Amber DEGRADED on the board, ESP32 offline banner. Restart, and it recovers. |

## Backup plans

| Problem | Fallback |
|---|---|
| Camera or lighting fails | Switch the PipeGen source to the MP4 under /home |
| PipeGen down | Control & Test page: species buttons (marked TEST) prove the actuator path |
| Board misbehaves | Spare ESP32 with the same firmware. `tools/esp32_sim.py` isolates network vs firmware. |
| Venue Wi-Fi | Travel router or phone hotspot. Update the broker URI. |
| Everything | Recorded 90 s video + `docs/evidence/` offline copies |
